Marker Name Highlight

Owner: Vignesh  ·  Repo: vigneshrajsb.com  ·  Status: Done  ·  Updated: 2026-08-14

Overview

What: Hovering the masthead name "Vignesh" swipes a real-feeling highlighter band across it, which then stays for the rest of the visit, like ink on paper.

Why: One deliberate flourish of delight on the most personal element of the page, inspired by hand-drawn underlines on cmrg.me but pushed to a marker highlight. Ties the masthead to the pier footer through the sunset peach.

Success looks like: the swipe reads as a physical highlighter pass (uneven edges, slight overshoot, translucent ink the serif shows through), not a CSS background fade.

Plan & design

Decisions (owner interview, 2026-08-14): highlighter swipe behind the text; sunset peach sampled from the pier footer's reflection strokes; draws on first hover and persists; name only, nothing else adopts the marker language.

Mechanics: a wobbly hand-drawn band as an inline SVG data URI on .name::before, sized ~0.5em tall across the lower half of the glyphs with ~3% overshoot each side and a slight tilt. mix-blend-mode: multiply lets the Vollkorn ink read through the peach. Reveal is a left-to-right clip-path wipe on :hover; the resting state's transition duration is effectively infinite, so once drawn it never un-draws (pure CSS, no JS). Reduced motion gets the band instantly on hover with no wipe. Touch: iOS applies hover on first tap of the heading.

Scope: homepage h1 only (index.html is the only page with the masthead name). No markup changes beyond none at all: the band lives entirely in CSS.
