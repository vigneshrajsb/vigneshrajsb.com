Overview

What: Replace GoatCounter with PostHog for pageviews, per-post visitor counts, link-click tracking, and custom events for Chocolata masthead interactions.

Why (product intent): One place to answer "who visits which post, what do they click, and do they play with the dog" — richer than GoatCounter's pageview-only counts, while keeping the site's privacy-first posture (no cookies, no consent banner, no session replay).

Success looks like: PostHog Web Analytics shows visitors + views per path; link_click and chocolata_* events arrive from production; zero GoatCounter references remain.

Plan

Scope

In: PostHog JS snippet on all 6 pages via one shared analytics.js; delegated link-click capture; three Chocolata events in chocolata.js; GoatCounter removal; AGENTS.md doc update.

Out: reverse proxy (/ingest rewrites), session replay, identified users, feature flags, surveys, consent banner.

Build sequence

  1. Shared analytics.js: PostHog snippet, localStorage-only persistence, autocapture off, pageview on, link-click delegation.
  2. Swap GoatCounter tag for analytics.js include on all 6 HTML pages.
  3. Capture calls at Chocolata state transitions (belly rub, annoyed, woken).
  4. User creates the vigneshrajsb.com PostHog project; fill real token via connector.
  5. Validate locally (make check + browser), ship, confirm live events.

Design

Direction: No UI surface. Analytics is invisible by design; no visual changes to the site.

Impeccable review summary: N/A — no rendered interface.

Prototypes

None — direct implementation; the event schema is small enough to validate live.

Notes & callouts

Info

The Vercel PostHog integration provisions env vars, which a no-build static site cannot consume. The public phc_ token is pasted directly into analytics.js instead; that token is designed to be public.

Watch out

Event schema is the contract: $pageview (auto), link_click {href, text, external}, chocolata_belly_rub, chocolata_annoyed {via}, chocolata_woken. Rename only with a matching update to saved insights.
