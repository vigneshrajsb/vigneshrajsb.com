Overview

What: A small animated, interactive illustration of Chocolata (Vignesh's dog, a 65lb Doberman mix per the site's own copy) lying inline to the right of the "Vignesh" h1 in the masthead. When the cursor enters her proximity, her head turns and eyes track the mouse; hovering directly triggers extra delight (ear perk / head tilt); when idle, she blinks and breathes.

Why (product intent): The masthead aside already says "walking the dog." Chocolata makes the site's warmth literal and personal without adding chrome. She is the one deliberate moment of play on an otherwise still, editorial page.

Success looks like: Instantly reads as Chocolata herself (deep chocolate coat, floppy ears, chain collar, drawn from her photos); tracking feels alive, not gimmicky; zero jank; respects prefers-reduced-motion; no layout shift; fits the paperlike visual voice.

Plan

Approach, scope, and build sequence. Keep current; refactor the text when the plan changes.

Scope

In: base illustration variations for user confirmation; interactive SVG with head-turn + eye-track + hover delight + idle loop; proximity gating; reduced-motion fallback; integration into index.html masthead.

Out: oil-motion skill install; AI video-generation pipeline; scroll-driven animation; appearances on writing/ pages (may follow later).

Build sequence

  1. Base art confirmed: variant-A soft cel style, sphinx pose with one front leg extended, deep chocolate coat (done).
  2. Frame bank generation via parallel subagents driving codex image gen, every frame an edit of the awake base for consistency: 15-frame gaze grid (5 horizontal × 3 vertical), blink, drowsy, asleep (chain fixed), annoyed, belly-up, belly-up-happy. Each agent QCs its frames against the base and regenerates failures.
  3. Standalone rig harness at docs/feat/prototypes/puppet-rig.html: frame-based state machine (awake gaze-tracking / drowsy / asleep / annoyed / belly-up), tuning control panel, and an asset grid view of the full frame bank.
  4. Impeccable review subagent audit of the harness + frame consistency; iterate.
  5. Integrate into index.html masthead right of the h1; validate across breakpoints, touch, and reduced motion.

Design

Visual direction and design decisions. Filled through the delegated design workflow (build subagent, then Impeccable review subagent).

Direction: Soft cel-shaded cartoon (user's variant A) of Chocolata in a sphinx pose with one front leg extended, deep chocolate coat, chain collar. Frame-based state machine (oil-motion approach): 15-frame gaze grid + blink + sleep set + annoyed set (with 2 tweens) + roll set (3 tweens) + belly-up. Hard cel cuts (crossfade 0), typographic emotes in system tones. "No photos, no illustration" (DESIGN.md) is deliberately broken here as the site's single sanctioned exception.

Final user config (baked into production): {"size":110,"gap":0,"baseline":40,"xfade":0,"radius":245,"lerp":0.18,"blinkMin":2.5,"blinkMax":7,"blinkHold":130,"drowsyTimeout":8,"sleepTimeout":12,"breathing":true,"zzz":true,"shakeThreshold":5,"annoyedHold":2.5,"bellyDwell":4000,"transStep":150,"emoteRate":500} (debug stripped for production).

Impeccable review summary: Audit health 17/20, verdict "ship after fixes". Verified working: zero CLS, true idle quiet (0 rAF over 23s asleep), load discipline (1 frame before load event), clean AX tree, frame-accurate annoyed sequence, no overflow at 320px. Findings applied: docs excluded from deploys; hit box inset to her silhouette (stops accidental belly-rolls from the GoodRx link); breathing scoped to the visible frame; shake detection gated to over-dog; user-select scoped to coarse pointers with touch-callout; pointermove layout reads moved into the rAF loop; frame preload gated on document readiness; heart glyph pinned to text presentation; blink reschedule on reduced-motion toggle; radius scaled with render size. Deliberately kept against reviewer preference (user decision): the continuous heart stream during an intentional belly rub. Deferred: WebP/PNG8 re-encode of the frame bank.

Watch out

This feature is a sanctioned single exception; keep the dog quiet by default (idle loop must be barely-there) so the page still reads as still.
